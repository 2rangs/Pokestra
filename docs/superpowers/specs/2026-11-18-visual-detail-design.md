# 비주얼 디테일 고도화 — 설계

## 의도
기능과 밀도는 갖췄지만 "디테일이 70% 없는" 상태. Astryx(Meta 디자인 시스템)를 제대로 활용하고 디자인 규칙(AGENTS.md)을 지키면서,
포켓몬 세계의 시각 언어(타입 색, 박스 아이콘)를 입혀 포트폴리오 수준의 완성도를 만든다.

## 원칙
- AGENTS.md 그대로: 컴포넌트 props 우선 → 토큰 유틸리티, raw `<div>`/`style={{}}`/hex/px/임의 값 금지.
- 색은 테마로: 타입 색 18종은 `:root` 덮어쓰기가 아니라 Astryx 테마 확장(neutral을 import해 확장, 또는 실험적 theme editor)으로 토큰을 만든다. 라이트·다크 모두.
- 테마를 바꾸면 `astryx experimental theme editor show <name> --png`(또는 테마 미리보기)로 그림을 보고 확인해야 완료.
- 밀도 개선 원칙(시선·마우스·읽기, 6번)을 그대로 따른다.

## 구성 요소
1. **타입 색 토큰 + `TypeBadge`**
   - 18개 타입마다 배경·글자·테두리 토큰(라이트/다크), 대비 AA 이상.
   - `TypeBadge`(Token 기반 또는 Token 스타일 확장): 타입 아이콘 + 이름, 크기 sm/md, 배경이 타입 색. 기존 `TypeIcon`/타입 태그 사용처 전부 교체.
   - 상성 배수 칩(×4, ×2, ×½, ×¼, ×0)도 의미 색(위험/주의/안전) + 타입 색 테두리.
2. **박스 아이콘 (미니 포켓몬)**
   - 40px 이하 자리(검색 결과, 칩, 표, 진화 작은 노드, 팀 슬롯, 폼 목록 등)는 PC 박스 아이콘 사용.
   - 후보 순서: SV 아이콘 `sprites/pokemon/versions/generation-ix/scarlet-violet/icons/{id}.png` → 7세대 아이콘 `generation-vii/icons/{id}.png`(폼 다수) → 기존 도트.
   - `pokemonImageCandidates`에 `icon` 단계 추가(표시 크기 ≤ 40px), 픽셀 렌더링.
3. **디테일 패스 (화면별)**
   - 카드: 주 타입 색을 아주 옅게 깐 배경 또는 상단 띠, hover/focus 상태, 도감 번호 서체(tabular, 흐린 색).
   - 능력치 막대: 값 구간별 색(낮음~높음), 최고값 강조, 합계 행 정렬.
   - 섹션 머리말: 아이콘 + 제목 + 보조 설명의 일관된 패턴, 섹션 간 간격 리듬.
   - 빈 상태·로딩 스켈레톤·에러를 Astryx EmptyState/Skeleton으로 통일.
   - 상세 머리말: 주 타입 색 그라데이션 없이 은은한 타입 색 면(토큰), 세대·전설/환상 표시를 Token으로.
   - 마이크로 인터랙션: 행/카드 hover, 포커스 링, 탭 전환 — 테마 duration/easing, 감속 모션 존중.
4. **검증**
   - 1280/390, 라이트/다크 전/후 스크린샷. doctor purity가 늘지 않을 것. 대비 검사(타입 배지 글자 대비).
